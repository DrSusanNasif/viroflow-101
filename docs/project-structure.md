# Project structure

viroflow-101 is organized as a small reproducible bioinformatics project.

## Main folders

- `bin/`: Python helper scripts
- `data/`: input FASTA files
- `docs/`: project documentation
- `envs/`: future software environment files
- `logs/`: future log files
- `results/`: output files
- `scripts/`: Bash training scripts
- `tests/`: future test files
- `workflows/`: workflow-related files

## Main files

- `README.md`: project overview
- `main.nf`: Nextflow workflow entry point
- `nextflow.config`: Nextflow configuration
- `.gitignore`: files Git should ignore
